ENCOR Security Knowledge Base

ENCOR 350-401 v1.2 Domain 5 (Security — 20%) reference for ACLs, wildcard masks, CoPP, AAA, and Layer 2 security.

ACLs & Wildcard Bitwise Logic

Extended Access Control List (ACL)

Filters traffic based on Source IP, Destination IP, Protocol (IP, TCP, UDP, ICMP), and Layer 4 Port numbers. Best practice is placing Extended ACLs as close to the source as possible. Numbered 100–199 / 2000–2699 or Named.

Wildcard Mask (0 = Match, 1 = Ignore)

A 32-bit inverse mask used in Cisco IOS ACLs and OSPF/EIGRP network statements. A 0 bit requires an exact binary match; a 1 bit ignores that bit position. Keywords: host x.x.x.x equals 0.0.0.0, and any equals 0.0.0.0 255.255.255.255.

Top-Down Processing & Implicit Deny

IOS evaluates Access Control Entries (ACEs) sequentially from lowest sequence number to highest and stops at the first match. Every ACL ends with an invisible deny ip any any (or deny ipv6 any any) that drops unmatched packets.

Non-Contiguous Wildcard Masks (Odd/Even Matching)

Unlike subnet masks, wildcard bits do not need to be contiguous. For example, wildcard 0.0.0.254 checks only the last bit (0 = matches all even fourth octets; 1 = matches all odd fourth octets).

Control Plane & AAA Security

CoPP — Control Plane Policing

Protects the router CPU (Control Plane) from DoS floods by applying a Modular QoS CLI (MQC) service-policy to the control-plane interface, rate-limiting management and routing protocol traffic (BGP, OSPF, SSH) while dropping excess.

TACACS+ vs. RADIUS (AAA)

TACACS+ (TCP 49): Cisco-enhanced protocol that encrypts the entire packet payload and separates Authentication, Authorization, and Accounting (supports per-command CLI authorization). RADIUS (UDP 1812/1813): Open standard that encrypts only the password field and combines Authentication + Authorization.

Layer 2 Infrastructure Security

DHCP Snooping

Blocks rogue DHCP servers by classifying switch ports as Trusted (uplinks to legitimate DHCP servers) or Untrusted (access ports). Builds the DHCP Snooping Binding Table (MAC, IP, Lease, VLAN, Interface).

DAI — Dynamic ARP Inspection

Prevents ARP spoofing / Man-in-the-Middle attacks by intercepting ARP packets on untrusted ports and validating IP-to-MAC bindings against the DHCP Snooping Binding Table.

IPSG — IP Source Guard

Prevents IP address spoofing on untrusted Layer 2 access ports by dynamically filtering source IP (and optionally source MAC) traffic using the DHCP Snooping Binding Table.
